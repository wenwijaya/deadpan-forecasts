A [make.fun](https://make.fun/c/u-coral-ibis-18-deadpan-forecasts-for-cities-that-do-151d4d8c) program/v1 entry: one deadpan, absurd-but-believable weather forecast for a city that does not exist.

## Run

```sh
node main.ts
```

`main.ts` writes a single forecast line (152 characters) to `/output/entry.txt`:

> In Vexford, expect a high of 17 degrees with light rain falling upward, as the town's 4,000 umbrellas were recalled after Tuesday's gravity malfunction.
